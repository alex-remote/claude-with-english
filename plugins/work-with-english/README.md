# claude-with-english

在 Claude Code 里工作的同时练英语：写中文时实时看到英文译文，Claude 的英文回复每段带中文译文，生词和句子可以加进单词本并同步到 Anki。

在 Claude Code 的对话里输入下面这行安装：

```
/plugin install work-with-english --marketplace alex-remote/claude-with-english
```

装好后输入 `/wwe` 打开设置。数据和隐私、已知情况见 https://github.com/alex-remote/claude-with-english 。
